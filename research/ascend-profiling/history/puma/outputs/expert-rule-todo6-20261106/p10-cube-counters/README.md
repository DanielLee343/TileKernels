## Offline raw-record gate

Local source identity is the clean relevant-file version of `a41d46ad6ec5233d352e91495963e036aba8193e`; the archive reports profiler build `884ac969494a186a9c63ac45c4c39ad7289b3215`, which is not available as a local git object. The two identities are not assumed equivalent.

Local `data_bean.h/.cpp` describes A5 `FftsConstructA5` as 128 bytes: 4 uint16, 1 uint64, 4 uint16, 2 uint16, 1 uint32, 12 uint64. A block-PMU record has function type `0x29` in the low six bits at offset 0; block ID is uint16 at byte 26, subblock at byte 24, core type is low bit of uint16 at byte 20, and ten raw uint64 PMU values start at byte 32. `GetBlockData` assigns event IDs by positional pairing with the AIC event vector supplied to the parser; the records themselves do not establish those IDs. `device_data_parse.cpp:GetProfBinInfo` slices that vector into 10-event replay rounds; local `prof_args.cpp:LoadPmuVec` selects the full fixed array for kernel replay. In that local array round 2 zero-based slots 4,5,6 are events 768,789,790 respectively; round 6 slots 3,4,5 are 808,809,810. This is a hypothesis for the archived build, not independently evidenced configuration.

Applying the A5 record layout to archived `DeviceProf2.bin`, filtering function 0x29 and Cube core type 0, and matching `(block_id, sub_block_id)` against ArithmeticUtilization yields unique matching rows for all three cases: square 24/24, tail 25/25, BMM 28/28. In each case raw slots 4,5,6 match total/fp/int instruction CSV fields on every keyed row. Raw slot 5 is zero in every square and BMM row; it is 3 in 21 tail rows and zero in four. The sixth binary contains corresponding valid Cube records, while replay-specific total cycles differ, consistent with the local separate-round model. Such agreement supports the inferred layout and reproduces the presented fields; it does not independently identify the configured event or establish hardware counter validity. Each binary has one additional 128-byte record that is excluded by block/type filtering.
