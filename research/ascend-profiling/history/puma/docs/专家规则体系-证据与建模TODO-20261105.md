## 二、资源问题与证据：初版对照

下表保留最初的问题摘要；TODO 1 的冻结定义见[问题、字段、计算与结论边界](./专家规则体系-TODO1-问题证据定义-20261105.md)，包括混合执行和计算自身入口。不代表已建立对应规则。

| 要识别的问题 | 现有 Default 能直接说明什么 | 还需什么才能支持更强判断 | 当前不能宣称什么 |
|---|---|---|---|
| 同一数据被重复请求到 UB | GM→UB 总计数字节 G、指令数 N | 有效地址范围、归属、通路、对象和版本；只读约定可限定版本 | 不能用 G、带宽或命中率唯一算出重复率 |
| 请求拆分/粒度可能不合理 | b=G/N 及各 block 的平均值 | 请求大小分布、访问/尾部约束、可比任务下的专家表现 | b 小不自动意味着不合理 |
| 给定请求特征后的 MTE2 活动开销偏高 | G、N、活动量 A，BW=G/A | 可比的计量及资源条件、稳定的专家参考关系 | 不能把它当搬运总量或粒度本身的合理性检查 |
| 缓存相关服务成本异常 | 官方定义的事件/命中率、主存与通路计数 | 工作集、复用机会与访问上下文；事件分母正确 | 低命中率不自动表示低效；不能将主存字节差当精确命中字节 |
| 计算/搬运协同或等待异常 | Vector/MTE 活动、等待比例 | 同窗口时序与相应依赖证据，明确采样覆盖 | 活动量相加不是总耗时，不能由占比直接推关键路径 |
| 核间工作分配可能不佳 | 各 block 的字节、指令、活动与总时间分布 | 预期有效工作量、可用并行任务、尾块等条件 | 有活动不等于有效工作；不均匀不自动是错误 |

证据分三层：**观测量可计算 → 资源解释在条件下成立 → 偏离有诊断意义**。每条规则分别记录，不能用软件复算通过替代后两层。
